# CodeTrack

## AI-Powered Programming Skill Gap Analysis Platform

CodeTrack is an AI-powered platform that helps students identify their programming strengths and weaknesses through personalized assessments.

## Problem

Students often know that they are weak in programming but do not know which specific topics they need to improve.

## Solution

CodeTrack generates personalized programming assessments using AI. It evaluates theory and programming answers, analyzes performance topic-wise, identifies weak areas, and provides personalized recommendations.

## Features

- 🤖 AI-generated programming assessments
- 📚 Theory + programming questions
- 📊 Topic-wise performance analysis
- 💪 Strength identification
- ⚠️ Weakness detection
- 🚀 Personalized improvement recommendations
- 📈 Assessment history
- 💻 C programming support
- 🐍 Python programming support
- 🎯 Student dashboard
